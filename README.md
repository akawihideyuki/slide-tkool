# Slide Tkool

YouTube動画向けの静止画スライドを、ブラウザ上で素早く作るための軽量エディタです。

## 対応サイズ

- 通常動画: 16:9 / 1920×1080
- YouTube Shorts: 9:16 / 1080×1920

編集画面では自動的に縮小表示し、PNG出力時は上記の実解像度でレンダリングします。

## 主な機能

- 16:9 / 9:16 の切り替え
- 複数スライド作成・複製・削除
- タイトル・本文・画像・ボックス要素
- 要素のドラッグ移動・四隅ドラッグによるリサイズ
- 座標・サイズ・色・文字サイズ・揃え等の編集
- レイヤー順変更
- 4種類のレイアウトテンプレート
- 単色 / グラデーション背景
- 通常動画・Shorts向け安全領域の目安ガイド
- 現在スライドのPNG出力
- 全スライドのPNG一括出力
- プロジェクトJSON保存 / 読込
- IndexedDBへの自動保存・復元
- Undo / Redo
- キーボードによる位置微調整
- 画面幅900px以下でのスライド一覧・編集設定パネル切り替え
- テキストが枠に収まらない場合の編集画面警告

> Shortsの「安全領域ガイド」はYouTube UIの固定仕様を保証するものではなく、編集時の目安です。端末やUI変更によって表示領域は変わる可能性があります。

## 使い方

1. `index.html` をWebサーバー経由で開きます。
2. 上部で `16:9 通常` または `9:16 Shorts` を選びます。
3. 左側でスライドを追加し、中央キャンバスで要素を選択・移動・リサイズします。
4. 右側パネルでテンプレート、背景、選択要素の設定を変更します。
5. `PNG出力` または `全PNG` で動画編集用素材を書き出します。

JavaScript Modulesを使用しているため、`file://` 直開きではなくWebサーバー経由での利用を推奨します。

### 簡易ローカルサーバー例

Pythonが入っている環境なら、リポジトリのフォルダーで次を実行できます。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開いてください。

## キーボード操作

- `Ctrl + Z`: 元に戻す
- `Ctrl + Y`: やり直す
- `Delete` / `Backspace`: 選択要素を削除
- `← ↑ → ↓`: 選択要素を1px移動
- `Shift + ← ↑ → ↓`: 選択要素を10px移動

入力欄を編集中は、上記の要素操作ショートカットを抑止します。

## プロジェクトJSONの画像

画像はプロジェクトJSON内へ `data:image/...` 形式で埋め込みます。安全性とPNG出力の互換性を保つため、読み込んだJSONに外部URLの画像が含まれている場合は読込を中止します。元画像をこのツールから追加し直してください。

## 構成

```text
slide-tkool/
├─ index.html
├─ styles.css
├─ README.md
├─ AGENTS.md
├─ tests/
│  ├─ static-check.mjs
│  └─ model-check.mjs
└─ js/
   ├─ app.js       # UI・操作・履歴・入出力
   ├─ model.js     # Project / Slide / Element データモデル
   ├─ renderer.js  # Canvas描画・PNG生成・ヒットテスト
   ├─ resize.js    # 選択要素の四隅ドラッグリサイズ
   └─ storage.js   # IndexedDB自動保存
```

外部JavaScriptライブラリやビルド工程は使用していません。

## データ設計

プロジェクト内に複数のスライドを持ち、各スライドが背景と複数の要素を保持します。文字・画像・ボックスは共通のElementとして扱うため、今後テンプレート追加、自動生成、字幕・台本データからのスライド生成などへ拡張しやすい構造です。

## 検証

GitHub Actionsの `Validate` workflowで、JavaScriptの構文チェック、HTML/JavaScript参照の静的整合チェック、プロジェクトJSONの正規化チェックを実行します。ローカルでは次を実行できます。

```bash
node tests/static-check.mjs
node tests/model-check.mjs
```
